# Kazumi

![Kazumi](static/logo_readme.png)

> [!IMPORTANT]
> **本项目是 [Kazumi](https://github.com/Predidit/Kazumi) 的一个分支版本（fork），基于上游 [2.2.6](https://github.com/Predidit/Kazumi/releases/tag/2.2.6) 版本开发，上游功能已同步至 [2.3.9](https://github.com/Predidit/Kazumi/releases/tag/2.3.9)。**
> 我们在上游项目的基础上进行**功能加强**，重点新增了**本地媒体库**与**磁力下载**能力，并增强了播放器、弹幕与追番统计体验。
> 🎉 **v1.0.3 已发布**，核心功能已基本可用，可前往 [Releases](https://github.com/yoshinosk/Kazumi-Enhanced/releases) 下载体验；项目仍在积极开发中，功能与规则请以[上游仓库](https://github.com/Predidit/Kazumi)为准。

使用 Flutter 开发的基于自定义规则的番剧采集与在线观看程序——在上游 Kazumi 的基础上，重点增强本地媒体库、磁力下载（libtorrent）、播放器与追番统计能力。

## 支持平台

本分支仅针对以下平台构建与适配：

- Android 10 及以上
- Windows 10 及以上

> 上游还支持 macOS / Linux / iOS / HarmonyOS 等平台，如需使用请前往[上游仓库](https://github.com/Predidit/Kazumi)。

### 继承自上游的功能

以下能力来自上游 [Kazumi](https://github.com/Predidit/Kazumi)（基于自定义规则的番剧采集与在线观看程序），随上游同步持续更新（当前同步至 2.3.9），规则与用法以上游仓库为准：

- **规则与片源**：Xpath 自定义规则编辑器、规则仓库与规则导入 / 分享、批量导入规则、API 搜索规则的详情页地址模板、多视频源切换
- **番剧浏览**：番剧目录、番剧 / 图片搜索、番剧时间表、番剧详情与评论、角色信息
- **播放**：分集播放、硬件解码、高刷新率适配、倍速播放、番剧字幕、Anime4K 实时超分辨率、进度手势（拖回起点可取消）、Android 画中画
- **互动与数据**：番剧弹幕（含简繁转换、屏蔽规则 WebDAV 同步）、追番列表（卡片 / 列表双布局）、播放历史、番剧离线缓存下载、一起看
- **同步与网络**：WebDAV 跨设备同步、Bangumi 收藏同步、Bangumi 图片与 API 的 ECH / 镜像加速、代理设置
- **系统与外观**：Material 3 Expressive 界面、配色方案、DLNA 无线投屏、外部播放器播放、截图挑选面板、在线更新（安装类型可选）、Android 自定义下载目录、低内存模式三档、桌面托盘

### 本分支新增 / 增强的功能

> 以下为本分支相对上游的主要差异；未列出的基础能力均继承自上游。

#### 本地媒体库

- **目录扫描与分组**：递归扫描本地视频目录（后台 isolate），按文件名标题特征把混存目录自动拆分为多部番剧；支持多个根目录、Windows 目录实时监听、回到前台或文件变化自动重扫；逐层遍历容错（无权限 / 损坏目录只跳过，按真实路径去重避免 junction 环无限遍历）。
- **识别与搜刮**：基于 Bangumi 的元数据搜刮与自动匹配，支持文件夹级 / 单文件级识别结果与手动「修改识别结果」；搜刮失败时可选用 ffmpeg 抽帧走 trace.moe 以图搜番兜底，ffmpeg 路径可配置。
- **浏览与排序**：文件夹 / 番剧 / 网格海报墙三种视图；按首播日期、最近播放、最近更新、番剧季度、标题、文件数排序，分组型排序带吸顶分组标题；支持搜索、全库空间统计、未匹配卡片首帧缩略图、特别篇 / 剧场版徽章。
- **播放与续播**：应用内播放并联动弹幕、播放历史与追番进度；封面续播角标、「上次看到哪里」与相对时间、分集观看状态（已看完 / 看到 xx:xx / 上次观看高亮）、播完自动推进下一集；外挂字幕自动加载、多季目录排序。
- **缺集与管理**：缺集检测一键跳转磁力补集；番剧右键菜单（续播 / 详情 / 缺集检测 / 修改识别 / 删除），删除前列出文件夹、视频数与体量，二次确认后递归清理文件、搜刮结果与缩略图缓存。
- **与在线功能联动**：番剧详情页直接展示本地可播资源、播放页集数显示本地文件角标、搜索结果命中本地库提示、追番封面显示「本地 N」「缓存 N」角标；本地看完可联动 Bangumi 收藏 EP 进度，全集看完自动标记「看过」。
- **历史修复**：旧版本遗留的占位番剧历史自动迁移到真实番剧条目。

#### 磁力搜索与下载

- **搜索**：内置 Mikan 与 AnimesGarden 两个搜索源，支持字幕组筛选、搜索历史（最多 20 条，可单条删除或一键清空）、结果长按 / 右键快捷操作（下载、复制磁力链 / 标题、查看详情）。
- **RSS 订阅**：支持 Mikan RSS 与 AnimesGarden 关键词订阅，检查间隔 30 分钟 ~ 1 天，打开应用或添加订阅时立即检查；订阅列表显示封面并支持自动下载开关、去重。
- **添加任务**：支持磁力链接、种子直链、本地 `.torrent` 种子文件与剪贴板自动识别；可选择种子内部分文件下载；每个任务可单独指定下载目录（支持添加时询问并记住上次选择）；按 info-hash 归一化去重。
- **下载引擎**：基于 libtorrent 的内置引擎；支持并发数与队列调度、全局 / 时段限速、仅 WiFi 下载、磁盘空间检查、失败重试、手动校验；可配置监听端口、最大连接数、上传 / 下载限速、做种停止策略、DHT、UPnP、强制加密、IPv6 与 tracker 自动更新。
- **做种与恢复**：做种可按时长或分享率自动停止（时长最低 1 小时）；种子元数据持久化缓存，重启后免等待 DHT 即可续传 / 续做种；对「刚创建就 100%」等假完成 / 假做种做二次校验。
- **边下边播与自动入库**：未完成任务可通过内置 HTTP 流边下边播；下载完成后可自动搜刮，达到置信度阈值时可自动移入媒体库，未达标标记「待确认」供手动匹配 / 重新搜刮，已入库任务显示「已入库」。
- **任务管理**：按添加时间倒序、按番剧分组与缺集检测、任务搜索、清除已完成、单任务 / 多选批量 / 整组删除（可同时删除文件）、集数范围标签、下载统计与全部暂停 / 继续。
- **系统集成**：下载完成 / 失败系统通知、Android 前台服务保活、后台低频刷新、WiFi 与移动网络切换即时暂停 / 恢复。

#### 播放器增强

- **字幕样式**：字号、加粗、颜色、描边、背景不透明度均可自定义，带实时预览，播放中调整立即生效。
- **轨道与画面**：音轨 / 字幕轨道选择、字幕延迟、A-B 循环、播完动作（自动连播 / 单集循环 / 播完暂停）、画面旋转、Windows 渲染器可选（auto / gpu / gpu-next）。
- **操作与快捷键**：底栏「上一集」与静音按钮、自定义倍速（0.25 ~ 8x）、移动端双击快进 / 快退、桌面悬停音量滑块、Windows 音量最高 200%、进度条悬停显示时间气泡、画面右键打开「更多选项」菜单。
- **截图**：Windows 快捷键截图并保存为文件（默认 S 键，目录可自定义），文件名自动带「番剧标题 + 集数 + 播放进度」，连按不会覆盖；与上游的截图挑选面板并存。
- **超分辨率**：Anime4K 扩展为官方六档（效率、降噪、均衡、质量、均衡增强、极致），新增 Restore_CNN_Soft 与 Upscale_Denoise_CNN_x2 着色器，随更新整体覆盖生效。
- **收尾引导**：最后一集播完可引导前往详情页在线播放或搜索磁力补集。

#### 弹幕增强

- **时间轴校准**：基于弹幕时间分布的头尾空白、越界信号与密度形态自动检测偏移，给出推荐偏移与置信度，避免片头 / 片尾自然空窗误判。
- **作用域记忆**：偏移按「番剧:分集」持久化，单集校准不会污染同番剧其他集数；历史遗留的全局偏移会自动清理。
- **弹幕池面板**：播放器弹幕面板提供当前弹幕池列表与时间轴快捷调整（±1 秒、±10 秒、恢复无偏移）。
- **倍速修复**：逐 tick 补发区间内整秒弹幕，修复非 1 倍速播放时弹幕丢失或重复的问题。

#### 追番统计与补标

- **追番统计页**：收藏按放送年份 / 季度归档浏览，提供单年各季度与历年的追番曲线、各状态数量总览、状态分布环形图、评分分布柱状图（含平均分）。
- **统计交互**：季度列表支持按收藏状态筛选（在看 / 想看 / 搁置 / 看过 / 抛弃）与组内排序（评分 / 收藏时间 / 标题）；支持多选批量修改收藏状态或删除；视图大小可选大 / 中 / 小，设置自动记忆。
- **季度补标页**：按年份 / 季度浏览 bgm.tv 动画条目，点按卡片单条打标，支持多选批量标记；统计页各季度标题可一键直达对应季度。
- **记录导入导出**：支持导出 / 导入 bangumi-note 兼容的追番记录 JSON，导入按原状态还原且不覆盖已有收藏。
- **评分详情**：番剧详情页点击评分可查看平均分、Bangumi 排名、评分人数与 1 ~ 10 星评分分布明细；修复排名恒为 0、评分人数与分布不一致等问题。

#### 桌面端与外观

- **自定义背景图**：可选择本地图片作为全应用背景，支持毛玻璃模糊强度与不透明度调节；页面、卡片、吸顶标题栏统一为半透明玻璃表面，页面切换淡入淡出。
- **全局 ESC 返回**：桌面端所有带返回按钮的页面均可按 ESC 返回；输入文字时不误触发，弹窗打开时优先关闭弹窗。
- **双击标题栏**：在最大化 / 还原之间切换。
- **右键菜单与多选**：播放器画面、媒体库番剧、磁力任务与分组均支持右键菜单；磁力任务支持多选批量暂停 / 继续 / 删除。
- **导航与宽屏布局**：底部导航新增「下载」与「媒体库」标签页，磁力搜索 / 磁力下载 / RSS 订阅 / 离线缓存统一到下载中心；下载中心在宽窗口下改用左侧边栏切换分类，分类标签改为标题栏内胶囊样式。
- **开机自启**：Android / Windows 可设置随系统启动（默认关闭）。
- **默认启动页**：在上游选项基础上新增「媒体库」作为启动页。

#### 其他

- **首页「继续观看」**：一键续播上次观看的番剧与进度，更早记录以封面列表快速切换。
- **时间线「只看日本动画」**：番剧时间表可按地区过滤。
- **详情页标题复制**：点击番剧标题即可复制，方便分享或搜索。
- **检查更新接入本仓库**：更新检查、下载与「更新日志」链接均指向本仓库，避免误更新为上游官方版本而丢失本分支增强功能。

## 从源码构建

```bash
# 拉取依赖并生成代码
flutter pub get
dart run build_runner build --delete-conflicting-outputs

# Windows
flutter build windows --release

# Android（按架构分包）
flutter build apk --release --split-per-abi
```

- 弹幕匹配依赖 DanDanPlay 开放平台，凭据通过 `--dart-define` 注入（`DANDANAPI_APPID` / `DANDANAPI_KEY`），需自行申请后参考 `tools/build_windows_local.ps1` 与 `tools/build_android_local.ps1` 的注入方式传入；未提供时仅弹幕匹配相关功能不可用，其余功能不受影响。
- 编译依赖托管在 MavenCentral / GitHub / SourceForge 上的资源，如位于中国大陆，可能需要设置恰当的镜像地址。
- `third_party/libtorrent_flutter` 与 `third_party/ech_http` 为本地 vendored 依赖（经 `dependency_overrides` 指向），修改其中的原生代码后需重新编译原生库。

## 常见问题

### Q: 为什么少数番剧中有广告？

A: 本项目未插入任何广告，广告来自视频源。请不要相信广告中的任何内容，并尽量选择没有广告的视频源观看。

### Q: 为什么我启用超分辨率功能后播放卡顿？

A: 超分辨率功能对 GPU 性能要求较高，如果没有在高性能独立显卡上运行，请尽量选择效率档而非质量档。对低分辨率视频源而非高分辨率视频源使用超分，也可以降低性能消耗。

### Q: 为什么播放视频时内存占用较高？

A: 本程序在视频播放时会尽可能多地将视频缓存到内存，以提供较好的观看体验。如果内存较为紧张，可以在播放设置中启用低内存模式来限制缓存。

### Q: 为什么少数番剧无法通过外部播放器观看？

A: 部分视频源的番剧使用了反盗链措施，这可以被 Kazumi 解决，但无法被外部播放器解决。

### Q: 为什么磁力搜索没有结果或速度很慢？

A: 磁力搜索依赖第三方搜索源，下载速度取决于 BT 网络中该资源的做种数量，冷门资源无速度属正常现象。可以尝试更新 tracker 列表、稍后重试，或改用其他搜索源。

### Q: 为什么我的自定义规则无法实现检索，或无法观看？

A: 目前对 `Xpath` 语法的支持并不完整，仅支持以 `//` 开头的选择器，建议参照示例规则构建自定义规则。若可以检索但无法观看，可尝试关闭规则中的「使用内置播放器」选项，改用 WebView 播放提高兼容性；内置播放器可用时建议启用，以获得更流畅且带有弹幕的体验。
